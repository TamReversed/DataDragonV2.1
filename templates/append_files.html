How Append Files works

What it does

Puts the rows of each file under the rows of the one before. Columns are matched by name, not by position, so the files may have their columns in a different order.

When a column is not in every file

The table shows which file has which column. A column that only some files have is kept, and left blank for the rows of the other files. If the same column has a different name in one file ("Vendor" and "Vendor Name"), say which column it is the same as.

The result

One table whose row count is the sum of the files, with a first column naming the file each row came from (optional). Only the first sheet of a workbook is used; use Open a File first for another sheet.
