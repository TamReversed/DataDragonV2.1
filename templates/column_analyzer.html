How Column Analyzer Works

What This Tool Does
The Column Analyzer provides comprehensive statistical analysis of your data columns. It analyzes each column to provide insights including data types, null counts, unique values, statistical measures for numeric columns, top values for categorical columns, and more.
How It Works
  • File Upload: Your Excel/CSV file is temporarily saved to the server's upload folder
  • Reading: The file is read into memory using pandas.read_excel() or pandas.read_csv()
  • Overview Analysis: Overall dataset statistics including shape, memory usage, duplicate rows
  • Column Analysis: Each column is analyzed individually for type-specific statistics
  • Numeric Columns: Mean, median, std dev, quartiles, skewness, kurtosis, outliers (IQR method)
  • Categorical Columns: Top 10 values, value counts, string length statistics
  • Date Columns: Date range (min/max) analysis
  • Boolean Columns: Value counts for True/False
  • Results Storage: Analysis results are temporarily stored in memory (not saved to disk)
  • Cleanup: Original upload file is deleted after analysis
Technologies Used
  • pandas: For reading files, data manipulation, statistical analysis
  • openpyxl/xlrd: Excel file format support
  • Flask: Web framework for handling requests
  • Server-Sent Events (SSE): Real-time progress updates
  • Chart.js: Client-side chart rendering for visualizations
  • jsPDF/html2canvas: PDF export functionality
File Storage & Locations
Upload Location:
[BASE_DIR]/uploads/[session_id]_[filename]
Output Location:
Stored temporarily in memory (analysis_results dictionary) - NOT saved to disk

Note: This tool does NOT save any analysis files to disk. All analysis results are stored temporarily in server memory and are cleaned up automatically after being fetched or after 1 hour. The original uploaded file is deleted immediately after analysis.

Processing Flow
  1. File is uploaded and validated (must be .xlsx, .xls, or .csv)
  2. File is saved temporarily in the uploads folder
  3. Background thread starts processing
  4. Excel/CSV file is read entirely into memory
  5. Dataset overview analysis (shape, memory, duplicates)
  6. Each column is analyzed individually for type-specific statistics
  7. Numeric columns: statistical measures calculated
  8. Categorical columns: top values and counts identified
  9. Date/Boolean columns: specific analysis applied
  10. Results stored temporarily in memory (session-based)
  11. Original upload file is deleted
  12. Results are sent to client via SSE and can be exported as PDF
