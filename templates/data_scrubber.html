How Data Scrubber Works

What This Tool Does
The Data Scrubber anonymizes sensitive data in selected columns while preserving data structure and relationships. It replaces original values with anonymized IDs that maintain referential integrity when relationship preservation is enabled.
How It Works
  • File Upload: Your Excel/CSV file is temporarily saved
  • Column Selection: Select columns to anonymize
  • Relationship Preservation: Optional: preserve relationships between columns (same original values get same anonymized IDs)
  • Anonymization: Original values are replaced with anonymized IDs using the column name as prefix (e.g., "FirstName_1", "FirstName_2", "Email_1", "Email_2")
  • Mapping Generation: Optional: generate a mapping file showing original to anonymized values
  • Verification: Pre-save and post-save verification ensures data is properly anonymized
  • Export: Anonymized file is saved, and optionally a mapping key file
  • Cleanup: Original upload file is deleted after processing
Technologies Used
  • pandas: Data manipulation and value replacement
  • openpyxl/xlrd: Excel file format support
  • Flask: Web framework
  • Server-Sent Events (SSE): Real-time progress updates

Processing Flow
  1. File is uploaded and validated
  2. User selects columns to anonymize
  3. User chooses relationship preservation option
  4. Background thread starts processing
  5. File is read into memory
  6. Unique values in selected columns are identified
  7. Anonymized IDs are generated for each unique value
  8. Values are replaced throughout the dataframe
  9. Pre-save verification checks anonymization worked
  10. Anonymized file is saved to output folder
  11. Post-save verification confirms saved file is correct
  12. Optional mapping file is generated
  13. Original upload file is deleted
  14. Files are made available for download
