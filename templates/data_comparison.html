How Data Comparison Works

What This Tool Does
The Data Comparison tool compares two Excel/CSV files to find differences. It identifies added rows, removed rows, and changed rows based on key columns, perfect for validating data migrations or auditing changes.
How It Works
  • File Upload: Both files are temporarily saved
  • Key Column Selection: Select key columns that uniquely identify rows
  • Comparison Column Selection: Select columns to compare for changes
  • Comparison: Rows are matched by key columns
  • Difference Detection: Added, removed, and changed rows are identified
  • Report Generation: Excel file with detailed comparison results
  • Export: Results include added rows, removed rows, and changed rows with before/after values
  • Cleanup: Original upload files are deleted
Technologies Used
  • pandas: Data manipulation and comparison logic
  • openpyxl: Excel file writing
  • Flask: Web framework
  • Server-Sent Events (SSE): Real-time progress updates
File Storage & Locations
Upload Location:
[BASE_DIR]/uploads/[session_id]_file1.[ext] and [session_id]_file2.[ext]
Output Location:
[BASE_DIR]/output/comparison_[timestamp].xlsx

Note: Output file contains sheets with added rows, removed rows, and changed rows (with before/after values). Original upload files are deleted after processing.

Processing Flow
  1. Both files are uploaded and validated
  2. User selects key columns and comparison columns
  3. Background thread starts processing
  4. Both files are read into memory
  5. Rows are matched by key columns
  6. Added rows (in file2 but not file1) are identified
  7. Removed rows (in file1 but not file2) are identified
  8. Changed rows (same key, different values) are identified
  9. Before/after values are captured for changed rows
  10. Excel file with comparison results is generated
  11. Original upload files are deleted
  12. Comparison report is made available for download
