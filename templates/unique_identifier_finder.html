How Unique Identifier Finder Works

What This Tool Does

This tool finds which columns you can concatenate (combine together) to create a unique ID for each row in your data.

Example: If you have columns "FirstName" and "LastName", and combining them creates unique values for each row, that's a viable ID combination. The tool finds the smallest number of columns needed.

The tool first removes fully duplicate rows (where all columns are identical), then analyzes your selected columns to find minimal combinations that create unique identifiers.

How It Works
  • File Upload: Your Excel/CSV file is temporarily saved
  • Column Selection: Select which columns to consider for creating unique identifiers
  • Duplicate Filtering: Fully duplicate rows (all columns identical) are automatically removed
  • Single Column Analysis: System checks if any single column creates unique IDs
  • Combination Analysis: If needed, tries pairs, triplets, etc. to find minimal combinations
  • Alternative Finding: Discovers multiple minimal combinations if they exist
  • Results Generation: Excel file with summary, data with unique IDs, and alternative combinations
  • Cleanup: Original upload file is deleted
Technologies Used
  • pandas: Data manipulation, duplicate filtering, and unique identifier analysis
  • itertools: Generating column combinations for analysis
  • openpyxl: Excel file writing
  • Flask: Web framework
  • Server-Sent Events (SSE): Real-time progress updates
File Storage & Locations
Upload Location:
[BASE_DIR]/uploads/[session_id]_[filename]
Output Location:
[BASE_DIR]/output/unique_identifier_[timestamp].xlsx

Note: Output file contains four sheets: "Summary" (statistics), "Data with Unique IDs" (original data with new Unique_ID column), "Alternative Combinations" (other minimal sets found), and "Sample Unique IDs" (preview). Original upload file is deleted after processing.

Processing Flow
  1. File is uploaded and validated
  2. User selects columns to analyze
  3. Background thread starts processing
  4. File is read into memory
  5. Fully duplicate rows are identified and removed
  6. System checks if single columns create unique IDs
  7. If not, tries combinations of 2, 3, etc. columns
  8. Finds minimal combination(s) that create unique identifiers
  9. Discovers alternative minimal combinations if available
  10. Results are compiled with unique IDs added to data
  11. Excel file with results is generated
  12. Original upload file is deleted
  13. Results file is made available for download
