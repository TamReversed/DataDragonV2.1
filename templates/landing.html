Comprehensive data analysis with statistical summaries, missing value analysis, outlier detection, and column insights. Perfect for understanding data shape and quality.

Data Scrubber

Anonymize sensitive data while maintaining exact data shape and relationships. Replace values with sequential IDs that preserve referential integrity across columns.

Duplicate Finder

Identify exact duplicates in any column and get a list of IDs to remove them, keeping the first occurrence as the original.

Find the minimal set of columns that create unique identifiers for each row. Automatically excludes fully duplicate rows and shows alternative minimal combinations.

Merge two Excel files using VLOOKUP/XLOOKUP-style joins. Perfect for combining GL accounts, vendor data, and financial transactions.

Data Comparison

Compare two Excel files to find differences. Identify added, removed, and changed rows. Perfect for validating data migrations, comparing GL balances, and auditing changes.

Column Comparison

Compare column names between two Excel files. See which columns are in each file, which are common, and which are unique. Perfect for schema validation and data mapping.

Transpose Data

Flip rows and columns - convert horizontal data to vertical (or vice versa). Perfect for restructuring client data where columns and rows are flipped.

Pivot Table Generator

Create powerful pivot tables from your Excel data. Summarize transactions by account and period, generate financial reports, and analyze spending patterns.

Data Validation

Validate your Excel data with custom rules. Check required fields, data types, ranges, patterns, and more. Perfect for validating GL imports, account codes, and financial records.

Column Normalizer

PDF to Word Converter
