    How recipes work

    Recording

    DataDragon remembers the steps behind each result while you work: clean the text, fill the blanks, use that result in the next tool, and so on. When every step can be replayed, the result can be saved as a recipe: a small file you keep.

    Which tools can be replayed

    Text Cleaner, Fill Missing, Remove Duplicates, Sort, Rank & Sample, Find & Replace and Row Filter. A result that passed through any other tool cannot be saved as a recipe yet.

    Replaying

    Give the new file and the recipe. "Check first" says what each step would do without writing anything. If a step no longer fits the file, for example because a column it uses is missing, the replay stops and names the step; nothing is half-done.

    The result

    The final table, a "Recipe steps" sheet with what each step changed, and any side outputs such as removed rows.
