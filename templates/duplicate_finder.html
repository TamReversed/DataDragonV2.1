How Duplicate Finder Works

What This Tool Does
The Duplicate Finder identifies duplicate rows based on selected columns. It creates a signature for each row by concatenating selected column values, then groups rows with identical signatures to find duplicates.
How It Works
  • File Upload: Your Excel/CSV file is temporarily saved
  • ID Column Selection: Select a unique identifier column (for tracking which rows to remove)
  • Duplicate Column Selection: Select columns to check for duplicates
  • Row Signatures: Each row gets a signature by concatenating selected column values
  • Grouping: Rows with identical signatures are grouped together
  • Duplicate Identification: Groups with more than one row are flagged as duplicates
  • Results Generation: Excel file with duplicate groups and IDs to remove
  • Cleanup: Original upload file is deleted
Technologies Used
  • pandas: Data manipulation, grouping, and duplicate detection
  • openpyxl: Excel file writing
  • Flask: Web framework
  • Server-Sent Events (SSE): Real-time progress updates

Note: Output file contains two sheets: "Duplicates" (summary) and "IDs to Remove" (single column for easy copy/paste). Original upload file is deleted after processing.

Processing Flow
  1. File is uploaded and validated
  2. User selects ID column and duplicate-check columns
  3. Background thread starts processing
  4. File is read into memory
  5. Row signatures are created by concatenating selected columns
  6. Rows are grouped by signature
  7. Duplicate groups (signatures with >1 row) are identified
  8. Results are compiled with IDs to remove
  9. Excel file with results is generated
  10. Original upload file is deleted
  11. Results file is made available for download
