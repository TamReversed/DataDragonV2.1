How Column Normalizer Works

What This Tool Does
The Column Normalizer converts column data types to your specified formats. You can transform columns to text, integers, floats, currency, dates, booleans, percentages, and more. Values are trimmed and formatted appropriately.
How It Works
  • File Upload: Your Excel/CSV file is temporarily saved
  • Column Analysis: Columns and sample values are displayed
  • Type Selection: Select data type for each column (currency, date, integer, etc.)
  • Transformation: Values are trimmed and converted to selected types
  • Formatting: Excel formatting is applied (currency symbols, date formats, percentages)
  • Export: New Excel file with normalized columns
  • Cleanup: Original upload file is deleted
Technologies Used
  • pandas: Data type conversion and transformation
  • openpyxl: Excel formatting (currency, date, percentage formats)
  • Flask: Web framework
  • Server-Sent Events (SSE): Real-time progress updates
File Storage & Locations

Note: Output file contains normalized columns with proper Excel formatting. Original upload file is deleted after processing.

Processing Flow
  1. File is uploaded and validated
  2. Columns and sample values are displayed to user
  3. User selects data type for each column
  4. Background thread starts processing
  5. File is read into memory
  6. Values are trimmed (whitespace removed)
  7. Each column is converted to selected type
  8. Excel formatting is applied (currency, date, percentage)
  9. New file is saved with normalized columns
  10. Original upload file is deleted
  11. Normalized file is made available for download
