How Column Comparison Works

What This Tool Does
The Column Comparison tool compares column names between two Excel/CSV files. It shows which columns are in each file, which are common to both, and which are unique to each file. Perfect for schema validation, data mapping, and understanding data structure differences.
How It Works
  • File Upload: Both files are temporarily saved
  • Column Extraction: Column names are read from the header row of each file
  • Comparison: All unique column names from both files are collected and sorted alphabetically
  • Result Generation: Excel file with a table showing each column and whether it appears in each file (Yes or No)
  • Statistics: Summary statistics showing total columns, common columns, and unique columns
  • Export: Download Excel file with the complete comparison table
  • Cleanup: Original upload files are deleted after processing
Technologies Used
  • pandas: Reading Excel/CSV headers and column extraction
  • openpyxl: Excel file writing with formatting (green checkmarks, red X marks)
  • Flask: Web framework
  • Server-Sent Events (SSE): Real-time progress updates
File Storage & Locations
Upload Location:
[BASE_DIR]/uploads/[session_id]_file1.[ext] and [session_id]_file2.[ext]
Output Location:
[BASE_DIR]/output/column_comparison_[timestamp].xlsx

Note: Output file contains a single sheet with three columns: "Column Headers" (all unique column names sorted alphabetically), "Found in [File 1 Name]" (Yes or No), and "Found in [File 2 Name]" (Yes or No). Original upload files are deleted after processing.

Processing Flow
  1. Both files are uploaded and validated
  2. Background thread starts processing
  3. Column headers are read from both files (only header row, not full data)
  4. All unique column names are collected and sorted alphabetically
  5. For each column, check if it exists in File 1
  6. For each column, check if it exists in File 2
  7. Create comparison table with columns and checkmarks/X marks
  8. Format Excel file with green backgrounds for checkmarks, red for X marks
  9. Original upload files are deleted
  10. Column comparison report is made available for download
