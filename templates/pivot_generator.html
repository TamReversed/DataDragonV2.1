How Pivot Table Generator Works

What This Tool Does
The Pivot Table Generator creates Excel pivot tables from your data. It allows you to define rows, columns, values, and aggregation functions to summarize and analyze your data, similar to Excel's pivot table functionality.
How It Works
  • File Upload: Your Excel/CSV file is temporarily saved
  • Configuration: Select rows (grouping dimension), columns (secondary grouping), values (aggregation fields), and aggregation function
  • Pivot Creation: pandas.pivot_table() is used to create the pivot table
  • MultiIndex Flattening: MultiIndex columns are flattened for Excel compatibility
  • Formatting: openpyxl applies professional formatting (colors, borders, number formats, totals)
  • Totals: Automatic row and column totals are added
  • Export: Formatted Excel file with pivot table, source data, and summary statistics
  • Cleanup: Original upload file is deleted
Technologies Used
  • pandas: pivot_table() function for pivot creation
  • openpyxl: Advanced Excel formatting (colors, borders, fonts, number formats)
  • Flask: Web framework
  • Server-Sent Events (SSE): Real-time progress updates
File Storage & Locations
Upload Location:
[BASE_DIR]/uploads/[session_id]_[filename]
Output Location:
[BASE_DIR]/output/pivot_[timestamp].xlsx

Note: Output Excel file contains multiple sheets: Pivot Table (formatted), Source Data, and Summary Statistics. Original upload file is deleted after processing.

Processing Flow
  1. File is uploaded and validated
  2. User configures pivot table (rows, columns, values, aggregation)
  3. Background thread starts processing
  4. File is read into memory
  5. pandas.pivot_table() creates the pivot table
  6. MultiIndex columns are flattened
  7. Pivot table is reset to convert index to columns
  8. Excel file is created with openpyxl
  9. Professional formatting is applied (row headers, data cells, totals)
  10. Source data and summary statistics are added as additional sheets
  11. Column widths are auto-adjusted
  12. Frozen panes are set for better navigation
  13. Original upload file is deleted
  14. Formatted Excel file is made available for download
