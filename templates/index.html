How the File Splitter Works

What it does
Divides one Excel file into several, each with the same columns and at most the number of rows you choose, and packs them into a ZIP. Text such as 00123 keeps its leading zeros, and text that looks like a formula stays text.
What happens to your file
The upload is read into memory and deleted as soon as it has been loaded. The ZIP stays downloadable for 30 minutes and is then deleted. It also contains _DataDragon_Log.json, a record of the split; the Excel files themselves contain nothing extra, so they can be loaded elsewhere as they are. Only the first sheet of a workbook is split; the page tells you if the workbook has more.
