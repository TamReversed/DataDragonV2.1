How Excel File Splitter Works

What This Tool Does
The Excel File Splitter divides large Excel files into smaller, manageable chunks based on the number of rows you specify. Each split file contains the same columns as the original, and files are automatically packaged into a ZIP archive for easy download.
How It Works
  • File Upload: Your Excel file is temporarily saved to the server's upload folder
  • Reading: The file is read into memory using pandas.read_excel()
  • Splitting: Data is divided into chunks using DataFrame.iloc[] slicing
  • Writing: Each chunk is saved as a separate Excel file using pandas.to_excel()
  • Zipping: All split files are packaged into a ZIP archive using Python's zipfile module
  • Cleanup: Temporary files and the original upload are automatically deleted after processing
Technologies Used
  • pandas: For reading and writing Excel files, data manipulation
  • openpyxl: Excel file format support (.xlsx files)
  • xlrd: Legacy Excel file support (.xls files)
  • zipfile: Creating ZIP archives
  • Flask: Web framework for handling requests
  • Server-Sent Events (SSE): Real-time progress updates
File Storage & Locations
Upload Location:
[BASE_DIR]/uploads/[session_id]_[filename]
Temporary Split Files:
[BASE_DIR]/output/[timestamp]/[base_filename]_[N]of[total].xlsx
Final Output:
[BASE_DIR]/output/split_files_[timestamp].zip

Note: All temporary files (individual splits and uploads) are automatically deleted after the ZIP file is created. Only the final ZIP file remains in the output folder and is available for download. Files are cleaned up immediately after processing to save disk space.

Processing Flow
  1. File is uploaded and validated (must be .xlsx or .xls)
  2. File is saved temporarily in the uploads folder
  3. Background thread starts processing
  4. Excel file is read entirely into memory
  5. File is split into chunks based on your "Records per file" setting
  6. Each chunk is written as a separate Excel file
  7. All split files are compressed into a single ZIP file
  8. Individual split files are deleted
  9. Original upload file is deleted
  10. ZIP file is made available for download
