How We Analyze Your Data
100% Deterministic - Zero AI/ML Used

DataDragon uses traditional, transparent algorithms to analyze your data. Every recommendation is based on clear, reproducible rules - not black-box machine learning. You can trust and verify every decision.

Sensitive Data Detection
We identify potentially sensitive columns using keyword pattern matching on column names:
  • name, email, phone - Personal identifiers
  • address, ssn, social - Location & government IDs
  • credit, account, salary - Financial information
  • password, dob, birth - Secrets & dates
This is simple substring matching - if your column name contains "email", we flag it. No guessing, no inference.
Data Type Detection
We detect data types by sampling and pattern analysis:
  • Numeric: Can the values be parsed as numbers?
  • Date: Do values match common date patterns (YYYY-MM-DD, MM/DD/YYYY, etc.)?
  • Currency: Do values contain currency symbols ($, EUR, GBP) with numbers?
  • Boolean: Are values limited to true/false, yes/no, 1/0?
We sample up to 1,000 non-null values and use regex pattern matching to determine the most likely type.
Natural Key Discovery
We find unique identifier combinations using the Apriori algorithm - a well-established data mining technique from 1994:
  • Level 1: Test each column individually for uniqueness
  • Level 2+: Only test combinations where ALL subsets were non-unique (Apriori pruning)
  • Result: Minimal column combinations that uniquely identify each row
This is exhaustive search with smart pruning - mathematically guaranteed to find all minimal keys.
Gap Analysis
Missing data detection is straightforward null counting:
  • Count NULL, NaN, empty string, and whitespace-only values
  • Calculate percentage: missing_count / total_rows x 100
  • Sort columns by missing percentage for prioritization
No imputation guessing - just the facts about your data completeness.
Why No AI?
  • Transparency: You can understand exactly why each recommendation was made
  • Reproducibility: Same data = same results, every time
  • Privacy: Your data never leaves your machine or gets sent to external APIs
  • Trust: No hallucinations, no probabilistic guesses, no unexplainable decisions
