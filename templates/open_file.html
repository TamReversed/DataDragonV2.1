How Open a File works

When to use it

Every tool reads the first sheet of a workbook and takes the first row as the column names. Use this page when the table is on another sheet, when there are title or blank rows above the column names, or when a text file is read with the wrong separator.

What it does

It shows the file exactly as it is stored. You say where the table starts, and it produces a clean table: column names in the first row, data below. Columns without a name are called Column 1, Column 2 and so on; if two columns share a name, the second gets _2.

Good to know

Nothing is converted: cells keep the values they have. Text files separated by semicolons, tabs or pipes are also recognised by the other tools on their own when the first line has no comma.
