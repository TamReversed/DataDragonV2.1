How Data Merge/Join Works

What This Tool Does
The Data Merge/Join tool combines two Excel/CSV files using VLOOKUP/XLOOKUP-style joins. You can perform inner, left, right, or outer joins based on key columns, similar to SQL JOIN operations.
How It Works
  • File Upload: Both files are temporarily saved
  • Key Column Selection: Select matching key columns from each file
  • Join Type Selection: Choose join type (inner, left, right, outer)
  • Column Selection: Select which columns to include from each file
  • Merging: pandas.merge() performs the join operation
  • Duplicate Handling: Optional handling of duplicate keys
  • Export: Merged Excel file with combined data
  • Cleanup: Original upload files are deleted
🔧 Technologies Used
  • pandas: merge() function for JOIN operations
  • openpyxl: Excel file writing
  • Flask: Web framework
  • Server-Sent Events (SSE): Real-time progress updates
File Storage & Locations
Upload Location:
[BASE_DIR]/uploads/[session_id]_file1.[ext] and [session_id]_file2.[ext]
Output Location:
[BASE_DIR]/output/merged_[timestamp].xlsx

Note: Output file contains the merged data from both files. Original upload files are deleted after processing.

Processing Flow
  1. Both files are uploaded and validated
  2. User selects key columns and join type
  3. User selects columns to include from each file
  4. Background thread starts processing
  5. Both files are read into memory
  6. pandas.merge() performs the join operation
  7. Duplicate key handling is applied if needed
  8. Merged data is compiled
  9. Excel file with merged results is generated
  10. Original upload files are deleted
  11. Merged file is made available for download
